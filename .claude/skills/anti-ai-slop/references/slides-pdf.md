# slides-pdf — 슬라이드·PDF 세부 기준

데크·보고서에서 AI 티를 만드는 건 그래픽이 아니라 **구조**다. 모든 장이 "제목 + 불릿 5개 + 같은 레이아웃"이면 템플릿 지문이 남는다. 시각 규칙(색·그림자·폰트)은 `visual-craft.md`와 동일하게 적용하고, 여기선 구조를 다룬다.

## 1. 한 장 = 한 주장 (assertion-evidence)

- 제목은 **주제가 아니라 주장**으로 쓴다.
  - ✗ "3분기 매출 현황" (주제 — 무슨 말을 하려는지 없음)
  - ✓ "3분기 매출 12% 감소, 신규 이탈이 원인" (주장 — 청중이 기억할 한 문장)
- 본문은 그 주장의 **증거**다. 불릿 요약이 아니라 그래프·표·단일 숫자 하나.
- 청중이 그 장에서 딱 하나만 가져간다면 무엇인가? 그게 제목이다.

## 2. 불릿은 최후의 수단

불릿 리스트는 관계를 못 보여준다. 대체를 먼저 시도한다.

| 정보 유형 | 불릿 대신 |
|-----------|-----------|
| 비교 (A vs B) | 2열 표, 나란히 배치 |
| 추세·변화 | 라인/바 차트, 화살표 |
| 프로세스·순서 | 좌→우 스텝 다이어그램 |
| 핵심 지표 | 큰 숫자 1개 + 라벨 (다른 건 다 지운다) |
| 구성·비중 | 단순 막대(파이 지양), 표 |

- 정말 불릿을 써야 하면 **한 장에 최대 3~4개, 각 1줄**. 문장이 아니라 구.
- 불릿 항목의 **길이·개수를 일부러 다르게** 한다. 모든 슬라이드가 딱 5개면 기계 티.

## 3. 레이아웃 다양성 — 템플릿 리듬 깨기

- 모든 장이 같은 그리드면 지문이 된다. **정보 유형에 따라 레이아웃을 바꾼다**: 전체 화면 숫자 1장, 2열 비교 1장, 좌측 도식+우측 설명 1장, 여백 많은 전환 장.
- 섹션 전환 슬라이드는 텍스트 최소 + 여백 최대. 숨 쉬는 장을 둔다.
- 헤더·페이지번호·로고 위치는 고정(일관성), 콘텐츠 영역은 자유(다양성). 이 둘을 헷갈리지 않는다.

## 4. 밀도 — 벽지 텍스트 금지

- 한 장을 소리 내어 읽어야 이해되면 텍스트가 너무 많다. 슬라이드는 문서가 아니다.
- 상세 설명은 **발표자 노트 / 부록(appendix)**으로 뺀다. 본 슬라이드는 주장 + 증거만.
- PDF 보고서(읽는 문서)는 슬라이드와 다르다. 여긴 문단으로 쓰되 `writing-tells.md` 규칙을 적용한다.

## 5. 출력 전 점검

- [ ] 각 슬라이드 제목이 주제가 아니라 주장인가?
- [ ] 불릿으로 처리한 것 중 표·도식·숫자로 바꿀 게 있는가?
- [ ] 모든 슬라이드가 같은 레이아웃·같은 불릿 수인가? (그렇다면 깨라)
- [ ] 소리 내 읽어야 이해되는 벽지 슬라이드가 있는가?
- [ ] 시각 규칙(그라데이션·글로우·기본폰트 금지)을 지켰는가? → `visual-craft.md`
