# visual-craft — 시각 산출물 세부 기준

SKILL.md 1번 섹션의 하드 게이트를 통과했다면, 이 문서로 **위계·간격·타이포**를 실제로 설계한다. 규칙은 "빼는 것"에서 끝나지 않는다. 뺀 자리를 위계와 여백으로 채워야 산출물이 선다.

## 1. 시각 위계 — 색·효과가 아니라 대비로 만든다

위계는 "무엇을 먼저 보게 할 것인가"의 설계다. 세 축만 쓴다.

- **크기**: 본문과 제목의 점프를 크게. 어정쩡한 1.2배 차이는 위계가 아니라 실수처럼 보인다.
- **굵기**: 강조는 색이 아니라 weight로. 회색 본문(#6b7280) + 검정 강조가 파란색 강조보다 고급스럽다.
- **색의 명도**: 같은 검정을 쓰지 말고 위계에 따라 명도를 낮춘다. 제목 #111, 본문 #374151, 보조 #6b7280, 비활성 #9ca3af.

원칙: **강조하고 싶으면 나머지를 죽여라.** 전부 굵으면 아무것도 굵지 않다.

## 2. 타입 스케일 — 모듈러 스케일

폰트 크기를 임의로 정하지 않는다. 하나의 비율로 스케일을 만든다. 실무 기본값(1.25 = Major Third):

```
12 · 14 · 16(본문) · 20 · 25 · 31 · 39 · 49
```

- 본문은 **16px 이상**. 웹 본문 14px는 답답하다.
- 줄간(line-height): 본문 1.5~1.6, 제목 1.1~1.25. 긴 텍스트일수록 넉넉히.
- 한 줄 길이(measure): **45~75자**. 넘으면 max-width로 자른다 (본문 ~65ch).
- 자간(letter-spacing): 본문은 건드리지 않는다. 큰 제목(≥31px)만 살짝 좁힌다(-0.01em~-0.02em).

## 3. 간격 — 8pt 그리드

여백을 눈대중으로 주지 않는다. 4의 배수, 기본은 8의 배수로 통일한다.

```
4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96
```

- **관련된 것은 가깝게, 무관한 것은 멀게** (근접성). 라벨과 값 사이 4~8px, 다른 항목과는 24~32px.
- 여백은 위계다. 섹션 사이 간격 > 문단 사이 > 줄 사이. 이 순서가 무너지면 구조가 안 읽힌다.
- 답답하면 십중팔구 여백 부족이다. 요소를 줄이지 말고 여백을 늘려라.

## 4. 색 — 무채색 베이스 + 액센트 1색

- 회색을 **여러 단계** 준비한다 (예: 50/100/200/…/900). 순수 회색보다 아주 살짝 채도 있는 회색(약간 쿨/웜)이 자연스럽다.
- 액센트는 **1색 계열**만. 상태색(성공 초록·경고 노랑·위험 빨강)은 액센트와 별개로 의미에만 쓴다.
- 큰 면적엔 채도 낮은 색, 작은 면적(버튼·링크)엔 채도 높은 색. 넓은 면을 쨍한 색으로 칠하지 않는다.
- **색만으로 정보를 전달하지 않는다.** 상태는 색 + 아이콘/텍스트로 이중 인코딩.

## 5. 폰트 선택 — 기본값 수렴 금지

`system-ui`/Arial/Roboto/Inter로 자동 수렴하지 않는다. 목적에 맞게 고르고 **왜 골랐는지 한 줄** 남긴다.

| 용도 | 추천 (본문) | 추천 (제목) |
|------|-------------|-------------|
| 문서·리포트 (가독성) | Source Serif, Lora, Charter | 같은 계열 굵게 |
| UI·대시보드 | IBM Plex Sans, Public Sans, Source Sans | 같은 계열 |
| 코드·데이터 | JetBrains Mono, IBM Plex Mono | — |
| 개성 있는 헤드라인 | — | Fraunces, Space Grotesk |

- 본문 + 제목 **2폰트까지**. 3폰트 넘어가면 산만하다. 한 폰트의 weight 대비로 해결되면 1폰트가 낫다.
- 웹폰트는 로딩 실패 대비 system 폴백을 스택에 둔다.

## 6. 자주 나오는 slop 패턴 → 교정

| Slop | 교정 |
|------|------|
| 보라→핑크 그라데이션 히어로 | 무채색 배경 + 검정 헤드라인, 대비로 시선 유도 |
| 컬러 글로우 그림자 뜬 카드 | `1px solid #e5e7eb` + 회색 그림자 1단계, 혹은 그림자 제거 |
| 카드 상단 4px 컬러 바 | 제거. 제목 weight로 구분 |
| hover 시 카드 확대·떠오름 | 배경색 아주 살짝 변화만 (기능적 피드백) |
| 이모지 불릿 리스트 | 텍스트 불릿 또는 표. 위계는 굵기로 |
| pill 뱃지 남발 | 정말 상태를 나타내는 1~2개만 |
