# writing-tells — AI 글쓰기 지문 세부 목록 + 교정

초안을 먼저 쓰고, 이 문서로 훑어 지문을 제거한다. 목표는 "AI 티 숨기기"가 아니라 **구체·판단·리듬을 넣는 것**이다. 넣으면 티는 사라진다.

## 1. 상투 어휘 — 발견 즉시 교체

**영어**: delve, tapestry, realm, testament, showcase, underscore, pivotal, multifaceted, meticulous, seamless(ly), robust, leverage(동사), navigate(비유), foster, boasts, elevate, unlock, embark, landscape(비유), crucial, vibrant, bustling.

**한글**: ~을 통해(반복), ~에 다름 아니다, 바야흐로, 화룡점정, 마침표를 찍다, 나침반이 되다, ~의 향연, 주목받고 있다, ~라 할 수 있다, 그야말로, 진정한, 손꼽히는.

교정 원칙: 상투어는 대개 **구체 동사·명사**로 바꾸면 사라진다.
- ✗ "AI를 leverage하여 효율을 unlock" → ✓ "AI로 리뷰 시간을 40% 줄였다"
- ✗ "다양한 기능을 seamless하게 제공" → ✓ "로그인·결제·알림을 한 화면에서 처리"

## 2. 구조적 지문

### 형용사 삼단 나열 (rule of three)
- ✗ "빠르고, 정확하고, 강력한 솔루션"
- ✓ "쿼리가 200ms 안에 끝난다" — 하나를 증거로 보이면 셋을 나열할 필요가 없다.
- 매 문단이 삼단 구조면 기계다. 가끔 쓰는 건 괜찮다. **습관이 문제**다.

### 부정 대구 (negative parallelism)
- ✗ "단순한 도구가 아니라, 파트너입니다" / "It's not just X — it's Y"
- 한 글에 한 번이면 강조, 세 번이면 지문. 대부분 그냥 **긍정문으로 바로** 쓰면 된다.

### "From X to Y" 나열
- ✗ "콘텐츠 제작부터 데이터 분석까지, 모든 것을"
- ✓ 실제 하는 두세 가지를 구체적으로 명명. "만능"을 암시하는 범위 나열은 정보가 0이다.

### 빈 메타 문장
- ✗ "이 글에서는 ~을 살펴보겠습니다" → 그냥 살펴보면 된다. 첫 문장부터 본론.
- ✗ "결론적으로, 우리는 ~을 확인했습니다" → "결론적으로" 빼고 결론만.
- ✗ "~은 아무리 강조해도 지나치지 않습니다" → 왜 중요한지 한 문장으로 보여라.

## 3. 톤·리듬 지문

### 과잉 헷징
- 모든 문장이 "~일 수 있습니다 / 아마도 / ~하는 경향이 있습니다"로 균일하게 조심스러우면 지문.
- 아는 건 단정하고, 모르는 건 모른다고 한다. 헷징은 **진짜 불확실할 때만**.

### em dash / 문장부호 남발
- 사람: em dash를 500단어에 1번꼴. AI: 50~80단어마다.
- 한 단락에 두 번 이상 나오면 줄인다. 대부분 쉼표·마침표·괄호로 대체된다.

### 균질한 리듬 (가장 강한 지문)
- 모든 문장이 15~20단어, 모든 문단이 3~4문장, 모든 섹션이 같은 소제목 수 → 기계.
- **비대칭을 의도적으로 넣는다**: 한 문장짜리 문단을 두려워하지 마라. 긴 설명 뒤에 짧은 못박기. 리듬이 사람을 만든다.

### 형식 지문
- 굵게 남발(강조가 강조를 죽인다), 이모지 불릿, 모든 항목에 콜론+설명 붙이기.

## 4. 넣을 것 (지문 제거보다 중요)

- **구체 명사·숫자·고유명**: "상당한 개선" → "응답 P95가 820ms→210ms". 추상 형용사를 데이터로.
- **판단과 근거**: 뭘 권하고 왜인지, 반례는 뭔지. 균형 잡힌 나열이 아니라 **입장**. AI는 중립적으로 다 나열하고, 사람은 고른다.
- **비대칭 리듬**: 짧은 문장 + 긴 문장. (위 3-3)
- **군더더기 서론·결론 삭제**: 첫 문장부터 본론, "결론적으로" 없이 결론.

## 5. 출력 전 점검

- [ ] 상투 어휘(1번 목록)가 있는가?
- [ ] 형용사 삼단·부정 대구·"from X to Y"가 반복되는가?
- [ ] "이 글에서는/결론적으로/아무리 강조해도" 빈 메타 문장이 있는가?
- [ ] 모든 문장·문단·섹션 길이가 균질한가? (그렇다면 비대칭 주입)
- [ ] 추상 형용사가 구체 숫자·명사로 안 바뀐 채 남았는가?
- [ ] em dash가 한 단락에 두 번 이상인가?
- [ ] 저자의 판단·입장이 있는가, 아니면 중립 나열뿐인가?
