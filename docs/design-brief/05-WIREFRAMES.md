# 화면별 와이어프레임

화면 10개. 각각 위→아래, 좌→우 영역 분해 + 상태 변화. ASCII 박스는 비율 참고용이지 정확한 그리드가 아니다.

---

## 1. 랜딩 (`/`)

```
┌─────────────────────────────────────────────┐
│ SiteHeader (accent 배경, 64px, sticky)        │
├─────────────────────────────────────────────┤
│         히어로 밴드 (960px 컨테이너)           │
│  [헤드라인+설명+CTA]        [미니 프리뷰 카드]  │
│      flex:1                    300px 고정폭   │
├─────────────────────────────────────────────┤
│      기능 소개 (960px, 카드 grid auto-fit)     │
│   [카드] [카드] [카드] [카드] ...              │
├─────────────────────────────────────────────┤
│   워크스페이스 안내 2단 카드 (flex)             │
│   [개설하기]        [가입하기]                 │
├─────────────────────────────────────────────┤
│   "쓰는 법" 순서목록 (720px 좁은 컬럼)          │
├─────────────────────────────────────────────┤
│   클로징 밴드 (720px, 좌우 flex space-between) │
└─────────────────────────────────────────────┘
```

비로그인 전용 — 로그인 세션 있으면 렌더 없이 `/dashboard`로 즉시 redirect. 미니 프리뷰 카드는 실제 스크린샷이 아니라 lucide 아이콘 기반 목업(그래픽 자산 없음).

## 2. 로그인 / 회원가입 (`/login`, `/signup`)

```
┌─────────────────────────────────────────────┐
│ SiteHeader                                    │
├─────────────────────────────────────────────┤
│                                                │
│              [Card, 화면 중앙]                 │
│              제목                              │
│              폼 필드들 (Form/FormField)         │
│              [제출 버튼]                        │
│              하단 링크(회원가입↔로그인 전환)      │
│                                                │
└─────────────────────────────────────────────┘
```

페이지 전체가 이 카드 하나뿐. 다른 장식 없음.

---

## 3. 초대 수락 결과 (`/invitations/accept`)

로그인/회원가입과 동일한 "헤더 + 중앙 카드" 골격. 카드 안 내용이 서버에서 검증한 토큰 상태 5분기에 따라 완전히 다르다:

| 상태 | 아이콘/톤 | 버튼 |
|---|---|---|
| 성공 | 긍정 아이콘 | 해당 워크스페이스로 이동 |
| 만료 | 경고 아이콘 | 대시보드로 이동 |
| 이미 사용됨 | 경고 아이콘 | 대시보드로 이동 |
| 다른 계정으로 로그인됨 | 경고 아이콘 | 로그인 페이지로(재로그인) |
| 무효한 토큰 | 에러 아이콘 | 대시보드로 이동 |

로딩 화면 없음 — 서버(RSC)가 토큰 검증을 끝낸 뒤에야 HTML이 나가므로 클라이언트 로딩 스피너 자체가 존재하지 않는다.

## 4. 대시보드 (`/dashboard`)

```
┌─────────────────────────────────────────────┐
│ SiteHeader                                    │
├─────────────────────────────────────────────┤
│         680px 중앙 컬럼                        │
│  ┌───────────────────────────────────────┐   │
│  │ 내 워크스페이스          [워크스페이스 만들기] │   │
│  ├───────────────────────────────────────┤   │
│  │ ┌─────────────────────────────────┐   │   │
│  │ │ [카드리스트 패널 — border+radius-lg] │   │   │
│  │ │  워크스페이스 카드 (세로 스택)         │   │   │
│  │ │  워크스페이스 카드                   │   │   │
│  │ │  ...                              │   │   │
│  │ └─────────────────────────────────┘   │   │
│  ├─ 구분선 ─────────────────────────────┤   │
│  │ 워크스페이스 참여 신청                   │   │
│  │ [검색창: "워크스페이스 검색"]             │   │
│  │  ┌─ 결과행: 이름 ─────── [신청]버튼 ┐   │   │
│  │  └───────────────────────────────┘   │   │
│  └───────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

**워크스페이스 카드 한 장**: 좌측 상단 이름(클릭 가능 링크)+역할 배지, 그 아래 "소유자 {이름} · 생성일 {날짜}", 그 아래 문서수/폴더수(아이콘+숫자, 0개도 표시), 우측 끝에 OWNER만 보이는 삭제(휴지통) 아이콘.

**검색 결과 행의 신청 버튼 3상태**: "신청"(가능) / "이미 멤버예요"(disabled) / "신청됨"(disabled, 신청 직후 즉시 전환) — 제출 중엔 "신청하는 중…", 성공/실패 메시지가 행 아래 별도 줄.

카드 0개인 빈 상태는 없음(회원가입 시 기본 워크스페이스 멤버십 자동 보장).

## 5. 워크스페이스 공통 셸 (`/w/[wsId]/*` 전체가 공유)

```
┌─────────────────────────────────────────────┐
│ SiteHeader (64px)                             │
├───────────┬───────────────────────────────────┤
│ 사이드바    │                                   │
│ 48~400px  │           메인 (flex:1)             │
│ 리사이즈   │        ↓ 화면 6/7/8/9 참고            │
│ 가능       │                                   │
│           │                                   │
└───────────┴───────────────────────────────────┘
   height: calc(100vh - 64px), 헤더 아래 고정 높이
```

**사이드바 내부 세로 순서**: 검색창(40px) → 헤더행(40px, "폴더" 라벨+새폴더/새문서 버튼 2개) → 루트 드롭존(평소 숨김, 드래그 중에만 나타남) → 트리 본문(스크롤, flex:1) → 휴지통 링크(40px) → 멤버 링크(40px) → 테마 토글(40px).

**사이드바 상태 3종**:
- **기본**(예: 260px): 아이콘+텍스트 전부 표시.
- **좁게 리사이즈**(100px 이하): "아이콘 전용 압축 모드" — 모든 라벨 텍스트·케밥 버튼이 사라지고 체브런+아이콘만 남는 순수 아이콘 레일. 새폴더/새문서 버튼이 가로→세로 스택.
- **접힘**(0px): 사이드바 자체가 사라지고 화면 좌측 가장자리에 펼치기 버튼(원형)만 남음. 리사이즈 핸들은 사이드바 우측 경계에 겹치는 투명 히트존, hover/드래그 시에만 accent 라인으로 보임.

**트리 노드 한 줄**: 체브런 → 아이콘(accent 고정색) → 이름 → hover 시 케밥. 드래그로 폴더/문서를 다른 폴더 또는 루트로 이동 가능(유효 타겟은 accent-weak 배경, 순환 이동 시도는 빨간 틴트+금지 커서). 우클릭/케밥 공용 컨텍스트 메뉴 — 폴더 5항목(새 하위 폴더/이름변경/이동/zip내보내기/삭제), 문서 2항목(md내보내기/삭제).

## 6. 워크스페이스 빈 상태 (`/w/[wsId]`)

메인 영역 전체가 중앙 정렬된 EmptyState 플레이스홀더 하나뿐(제목바도 상태바도 없음). "문서를 선택해 주세요" 같은 안내 문구 + 사이드바에서 문서를 고르라는 화살표성 힌트 정도가 적절한 자리.

## 7. 문서 편집 (`/w/[wsId]/d/[docId]`) — 이 사이트의 핵심 화면

```
메인 영역 안:
┌─────────────────────────────────────────────┐
│ titleRow (40px)                               │
│ [FolderPathPicker 브레드크럼]  [제목 입력창]      │
├─────────────────────────────────────────────┤
│ TagBar (40px, 정확히 좌우 50/50 분할)           │
│ [태그칩들+입력]           [저장/수정/삭제 버튼]   │
├─────────────────────────────────────────────┤
│ Toolbar (44px, 풀와이드, sticky)                │
│ [서식버튼 13개, 그룹구분]      [레이아웃모드 3버튼] │
├─────────────────────────────────────────────┤
│  카드 프레임(margin 8/16px, border+radius-lg)   │
│  ┌───────────────┬───────────────┐          │
│  │  에디터 (CodeMirror) │  미리보기       │          │
│  │                │                │          │
│  │  ←리사이즈 핸들→ (split 모드만)     │          │
│  └───────────────┴───────────────┘          │
├─────────────────────────────────────────────┤
│ SaveStatusBar (40px)                          │
└─────────────────────────────────────────────┘
```

**FolderPathPicker**(제목 앞 브레드크럼): "워크스페이스 / 폴더 / 하위폴더" 형태 버튼, 클릭 시 아래로 전체 폴더 트리 드롭다운이 열려 즉시 이동(모달 아님).

**TagBar 좌측**: 태그 아이콘 + 알약형 칩들(각 X 삭제 버튼) + 입력창. 3개 도달 시 입력 비활성화+placeholder 변경.

**TagBar 우측 — 문서 상태별 버튼**:
- **새 문서**(한 번도 저장 안 됨): "저장" 버튼 하나(primary).
- **조회 중 문서**(이미 저장된 적 있음): "수정"(secondary) + "삭제"(danger) 두 개.
- **Viewer 권한**: 버튼 영역 자체가 비어있음.

**레이아웃 모드 3종**(툴바 우측 세그먼트 버튼):
- 분할 — 에디터|미리보기 좌우 2컬럼, 핸들로 비율(20~80%) 조절.
- 에디터만 — 미리보기 패널 사라짐, 에디터가 전체 폭.
- 미리보기만 — 에디터 자체가 언마운트, 미리보기가 전체 폭(이 모드에선 서식 버튼이 무력화됨).

**저장 상태 3종**(SaveStatusBar): 저장중(스피너) / 저장됨(accent 배지) / 실패(에러+재시도 버튼).

**모달 2종**(이 화면에서 뜸): 저장 완료 확인(Modal, 버튼 우측정렬 1개), 삭제 확인(ConfirmDialog, destructive), 임시저장 복구 안내(있으면 페이지 진입 즉시 — 08 참고).

**미리보기 렌더 규칙**: 제목 h1~h4(28/22/18/16px), 본문 15px/1.65, 인용문(좌측 굵은 보더), 인라인코드(알약형 배경), 코드블록(테마 무관 고정 진한 배경+밝은 텍스트 — 유일하게 라이트/다크 안 바뀌는 영역), 표(테두리 셀, 헤더 행만 배경), 체크박스(accent-color).

## 8. 임시저장 복구 다이얼로그 (문서 편집 화면 진입 시 조건부)

서버가 "임시저장이 마지막 저장보다 최신"이라고 판단하면 페이지 진입 즉시 뜨는 확인창(ConfirmDialog 재사용). 제목 "임시 저장된 내용이 있어요", 버튼: "나중에"(닫기만, 다음 방문 시 재노출) / "복원"(즉시 삽입). 별도로 작은 "폐기" 텍스트 링크(서버 임시저장 완전 삭제).

## 9. 휴지통 (`/w/[wsId]/trash`)

메인 영역에 리스트만(별도 헤더 패널 없음). 한 행: 아이콘(폴더/문서) + 이름 + 삭제된 지 얼마나 됐는지(상대시간) + [복원]/[완전삭제] 버튼 쌍.

**권한별 버튼 상태**: 복원은 Editor 이상 활성, 완전삭제는 Admin 이상 활성 — **권한 없으면 버튼을 숨기지 않고 disabled + 바로 옆 회색 힌트문구**("편집자 이상만 복원할 수 있어요" 등)로 안내.

복원은 확인 없이 즉시 실행, 완전삭제는 ConfirmDialog(destructive, "되돌릴 수 없다" 경고 문구)로 재확인.

원래 부모 폴더가 이미 삭제돼 워크스페이스 루트로 대신 복원됐을 땐 상단에 정보 배너(RestoreRootBanner, X로 닫기 가능, 좌측 회색 보더 — destructive 아님 "안내" 톤)가 뜬다.

## 10. 멤버 (`/w/[wsId]/members`)

메인 영역, 테이블이 아니라 행(row) 리스트 3섹션:

```
멤버                                    ← 20px 제목
─────────────────────────────
승인 대기 중  (ADMIN 이상만 보임, 없으면 섹션 자체 숨김)
  [Mail] 이름/이메일   N분 전    [승인][거절]
─────────────────────────────
멤버 목록  (전원)
  이름  이메일   [역할 배지]
  이름  이메일   [역할 배지]
─────────────────────────────
회원 초대  (ADMIN 이상만)
  [검색창: 이메일/이름]
  결과행: 이름/이메일   [초대] 또는 [이미 멤버] 배지 또는 [✓ 초대 보냄]disabled
```

역할 변경 UI는 없음(현재 스코프 밖, 읽기 전용 배지). 승인/거절은 클릭 즉시가 아니라 ConfirmDialog 재확인을 거친다(거절은 destructive 톤).

## 부록: 모달/다이얼로그 총정리

이 사이트의 모든 팝업이 두 컴포넌트(Modal, ConfirmDialog) 중 하나를 재사용한다. 새 디자인도 "임의 커스텀 모달"보다는 이 두 셸을 얼마나 다양하게 채워 쓰는지 보면 전체 그림이 잡힌다.

| 이름 | 셸 | 트리거 | 파괴적? |
|---|---|---|---|
| CreateWorkspaceModal | Modal | 대시보드 "워크스페이스 만들기" | 아니오 |
| DeleteWorkspaceDialog | ConfirmDialog(이름 재입력) | 워크스페이스 카드 삭제 아이콘 | 예 |
| MoveFolderModal | Modal(트리 리스트) | 폴더 컨텍스트 메뉴 "이동..." | 아니오 |
| 폴더/문서 삭제 확인 | ConfirmDialog | 컨텍스트 메뉴 "삭제" | 예 |
| 저장 완료 알림 | Modal | 문서 "저장"/"수정" 클릭 성공 | 아니오 |
| DraftRecoveryDialog | ConfirmDialog | 문서 진입 시 자동(조건부) | 아니오(선택적 폐기는 파괴적) |
| 가입 승인/거절 확인 | ConfirmDialog | 멤버 페이지 승인/거절 버튼 | 거절만 |
| 휴지통 완전삭제 확인 | ConfirmDialog | 휴지통 "완전 삭제" 버튼 | 예 |
