# 핵심 사용자 흐름

화면 여러 개를 가로지르는 흐름 6개. 화면 번호는 05-WIREFRAMES.md 기준.

## 1. 첫 가입 → 첫 문서 작성

랜딩(1) → 회원가입(2) → 자동으로 기본 워크스페이스에 EDITOR로 가입된 채 대시보드(4)로 이동 → 워크스페이스 카드 클릭 → 워크스페이스 셸(5) → 빈 상태(6, 아직 문서 없음) → 사이드바 "새 문서" 버튼 → 인라인 제목 입력 → 문서 편집 화면(7)으로 즉시 이동, "저장" 버튼만 있는 새 문서 상태.

이 흐름은 회원가입 직후 단 한 번의 클릭 손실도 없이 첫 문서까지 도달해야 한다는 게 기존 요구사항(US 인수 조건)의 취지다 — 빈 워크스페이스 카드/빈 상태 화면에서 다음 액션(새 문서/새 폴더)이 시각적으로 바로 눈에 띄어야 한다.

## 2. 워크스페이스 생성

대시보드(4) "워크스페이스 만들기" → CreateWorkspaceModal(이름 필드 하나) → 제출 성공 시 모달 닫고 새 워크스페이스 셸(5)로 바로 이동, 생성자는 자동으로 OWNER.

## 3. 다른 워크스페이스에 참여 신청 → 승인

대시보드(4) 하단 검색창에 이름 입력(디바운스) → 결과 리스트에서 "신청" 클릭 → 버튼이 "신청됨"으로 즉시 전환+성공 메시지 → (다른 계정, ADMIN 이상) 멤버 페이지(10) "승인 대기 중" 섹션에서 신청자 확인 → "승인" 클릭 → ConfirmDialog 재확인 → 승인되면 신청자가 EDITOR로 편입되고 대기 목록에서 사라짐.

신청자 관점에서 "이미 멤버인 워크스페이스"와 "이미 신청 보낸 워크스페이스"는 검색 결과에서 버튼이 각각 "이미 멤버예요"/"신청됨"으로 disabled 처리돼 중복 신청이 UI 단에서부터 막혀야 한다.

## 4. 문서 작성 → 조회 상태 전환

문서 편집 화면(7)에서 "새 문서"로 진입(TagBar 우측에 "저장" 버튼만) → 제목/본문 입력 시작하면 1초 디바운스 자동저장이 백그라운드로 돌면서 SaveStatusBar가 "저장중…"→"저장됨"을 오간다 → "저장" 버튼을 수동 클릭하면 즉시 저장 + 저장완료 Modal → 페이지를 새로고침하거나 사이드바에서 이 문서를 다시 열면 이제 "조회 중 문서" 상태(TagBar 우측이 "수정"+"삭제"로 바뀜, "저장" 버튼은 사라짐).

이 상태 전환은 문서가 "한 번이라도 저장된 적 있는지"로만 갈리고, 같은 세션 안에서 실시간으로 바뀌지 않는다(다음 페이지 로드 시점에 서버가 다시 판단) — 디자인상 헷갈리지 않게 두 상태의 버튼 세트를 명확히 구분해야 한다.

## 5. 폴더/문서 조직

사이드바(5)에서: "새 폴더"로 루트에 폴더 생성 → 우클릭 → "새 하위 폴더"로 중첩 → 문서를 드래그해서 그 폴더 안으로 이동(드롭하면 서버 확인 후 트리 갱신, 낙관적 업데이트 없음) → 폴더를 다시 드래그해서 화면 상단 "워크스페이스 루트로 이동" 드롭존에 놓아 최상위로 복귀 → 우클릭 "삭제" → ConfirmDialog(하위 폴더/문서까지 함께 이동한다는 경고) → 확인 시 폴더와 그 안의 모든 문서가 한 번에 휴지통(9)으로 이동.

문서 편집 화면(7)의 FolderPathPicker 브레드크럼으로도 같은 이동이 가능하다 — 사이드바 드래그와 브레드크럼 드롭다운, 두 경로가 같은 이동 기능의 다른 진입점이라는 점을 디자인이 일관되게 표현해야 한다.

## 6. 초대 수락

ADMIN 이상이 멤버 페이지(10) "회원 초대"에서 이메일/이름 검색 → "초대" 클릭 → 대상자가 이메일로 받은 링크(`/invitations/accept?token=…`) 클릭 → 로그인 안 돼 있으면 로그인 화면으로 유도 후 복귀 → 초대 결과 화면(3)에서 5가지 상태 중 하나로 결과 확인 → 성공 시 해당 워크스페이스로 이동, 이미 EDITOR로 편입된 상태.

일회성 토큰이라 같은 링크를 두 번 클릭하면 "이미 사용됨" 상태로, 다른 계정으로 로그인한 채 클릭하면 "다른 계정으로 로그인됨" 상태로 각각 다른 안내가 나와야 한다 — 이 5분기는 UI에서 생략할 수 없는 필수 상태다(01-OVERVIEW.md "유지해야 하는 것" 참고).
