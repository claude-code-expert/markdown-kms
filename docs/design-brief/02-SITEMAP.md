# 사이트맵

## 라우트 그룹 구조

`src/app/` 아래 두 그룹이 있다 — `(auth)`와 `(main)`. 나뉜 기준은 인증 필요 여부가 아니라 **화면 골격**이다. `(auth)`는 로그인/회원가입/초대수락처럼 "헤더 + 중앙 카드 하나"인 일반 스크롤 페이지, `(main)`은 대시보드(일반 스크롤)와 `w/[wsId]`(사이드바가 있는 고정 높이 3분할 셸)를 함께 묶지만 그룹 자체엔 공통 레이아웃이 없고 각 하위 세그먼트가 필요한 헤더/셸을 직접 조립한다.

## 라우트 표

| 경로 | 접근 조건 | 화면 골격 | 목적 |
|---|---|---|---|
| `/` | 비로그인 전용(로그인 세션 있으면 `/dashboard`로 즉시 redirect) | 헤더 + 풀와이드 스크롤 | 마케팅 랜딩 |
| `/login` | 누구나 | 헤더 + 중앙 카드 | 로그인 폼 |
| `/signup` | 누구나 | 헤더 + 중앙 카드 | 회원가입 폼 |
| `/invitations/accept?token=…` | 로그인 필요(비로그인 시 callbackUrl 붙여 `/login`으로 redirect) | 헤더 + 중앙 카드 | 초대 토큰 검증 결과 5분기(성공/만료/이미사용/다른계정/무효) |
| `/dashboard` | 로그인 필요 | 헤더 + 680px 중앙 컬럼 스크롤 | 내 워크스페이스 카드 목록 + 생성/검색가입 |
| `/w/[wsId]` (레이아웃) | `requireRole(VIEWER)` 이상, 실패 시 404 위장 | 헤더 + 사이드바(리사이즈 가능) + 메인(가변폭) 고정 100vh | 하위 라우트 4개가 공유하는 셸 |
| `/w/[wsId]` (인덱스) | 위와 동일 | 셸의 메인 영역에 EmptyState만 | 문서 미선택 상태 |
| `/w/[wsId]/d/[docId]` | `requireRole(VIEWER)` 이상, 삭제 버튼은 EDITOR+만 | 셸의 메인 영역 = 3단(제목행/툴바/에디터+미리보기) | 문서 편집 |
| `/w/[wsId]/trash` | `requireRole(VIEWER)` 이상, 복원은 EDITOR+, 완전삭제는 ADMIN+ | 셸의 메인 영역에 리스트 | 삭제된 문서/폴더 복원·완전삭제 |
| `/w/[wsId]/members` | `requireRole(VIEWER)` 이상, 관리(초대/승인)는 ADMIN+ | 셸의 메인 영역에 섹션 3개 | 멤버 목록·역할·가입 승인 |

## 화면 밖 공통 요소

- **SiteHeader** — 위 표의 모든 라우트가 공유하는 단일 헤더. 로그인 상태에 따라 우측 버튼 구성이 바뀐다(비로그인: 로그인+회원가입, 로그인: 로그아웃). 상세는 05-WIREFRAMES.md.
- **전역 폰트/테마** — 루트 `layout.tsx`가 `theme` 쿠키를 RSC에서 읽어 `<html data-theme>`을 첫 렌더부터 세팅한다(깜빡임 방지). 값이 없으면(첫 방문) `prefers-color-scheme` 미디어쿼리로 폴백.

## 이 세션에 없는 것(재디자인 스코프 판단용)

프레젠테이션 모드, TOC 내비게이션, Google OAuth 로그인은 REQUIREMENT/PRD상 R3(P2)로 분류돼 있고 현재 코드베이스에 **구현되어 있지 않다**(제품 오너가 명시적으로 스코프 제외 결정). 재디자인 대상에서 제외한다.
