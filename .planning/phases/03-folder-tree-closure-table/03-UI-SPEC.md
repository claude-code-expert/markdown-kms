## Design System

| Property | Value |
|----------|-------|
| Tool | none — shadcn 미도입 (Phase 1/2 결정 그대로 유지) |
| Preset | not applicable |
| Component library | none — 순수 CSS Modules + `docs/ui-kit.html` 토큰(Phase 1이 `src/app/globals.css`에 이식) 재사용 |

**shadcn 미도입 근거 (재질문 대상 아님):** Phase 1/2 UI-SPEC과 동일 — CSS Modules + ui-kit 토큰이 확정 스택.

**이 phase가 신규로 설계하는 표면:** 워크스페이스 사이드바 트리(생성/이름변경/이동/소프트삭제 인터랙션 포함), 우클릭 컨텍스트 메뉴, hover 액션 버튼, 인라인 이름변경 입력, 드래그앤드롭 시각 피드백, "이동" 폴백 모달. **컨텍스트 메뉴·DnD는 신규 라이브러리를 추가하지 않는다** — 네이티브 HTML5 Drag and Drop API(`draggable`/`dragstart`/`dragover`/`drop`)와 자체 구현 팝업 메뉴로 충분하다(YAGNI — `dnd-kit` 등은 리사이즈 가능한 리스트 재정렬처럼 더 복잡한 요구가 생기기 전까지 불필요, `package.json`에 이미 해당 부류 의존성 없음).

| 규칙 | 내용 |
|------|------|
| 배치 | `w/[wsId]/page.tsx`를 세로 `.page`(기존 유지) 안에 `grid-template-columns: 260px minmax(0,1fr)` 두 칸으로 감싼다 — 좌측 사이드바, 우측에 기존 `<h1>` 타이틀 + `EditorPreviewLayout`. `height: 100%` 상속만 사용, `100vh`는 지금처럼 `page.tsx` 최상위 한 곳에서만 선언(Phase 2 규칙 재사용). |
| 사이드바 폭 | 260px 고정, 리사이즈 핸들 없음(요구사항에 없음 — Phase 5 레이아웃 전환 때 재검토 여지만 남김). **Exception:** 260은 8-point 콘텐츠 스페이싱 스케일 토큰은 아니지만 4의 배수인 레이아웃 값 — Phase 2가 툴바 44px를 예외로 둔 것과 동일한 성격. |
| 구분선 | 사이드바 우측에 1px solid `var(--border)` 세로선. 그림자·그라데이션 없음(anti-ai-slop). |
| 스크롤 | 사이드바 자체 독립 `overflow-y: auto`. 헤더(아래)는 스크롤 시 고정되지 않아도 된다 — 트리가 길어져도 사이드바 폭 안에서만 스크롤, 페이지 전체 스크롤 없음. |
| 헤더 | 사이드바 최상단 40px 행: 좌측 "폴더" 라벨(Label 스케일, `var(--muted)`), 우측 hover 없이 항상 노출되는 새 폴더 버튼(24×24, lucide `FolderPlus`, `var(--muted)` → hover 시 `var(--text)`) — 워크스페이스 루트에 새 폴더를 만드는 상시 진입점. 하단 1px solid `var(--border)`. |
| 반응형 | 이 phase 범위 밖(다른 Phase도 모바일 브레이크포인트를 다루지 않음) — 데스크톱 폭 전제, 별도 접힘 모드 없음. |

## Spacing Scale

Declared values (must be multiples of 4) — Phase 1/2와 동일 스케일 재사용:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 노드 아이콘-라벨 gap, hover 액션 버튼 내부 아이콘 패딩 |
| sm | 8px | 컨텍스트 메뉴 항목 padding, 노드 기본(depth 0) 좌측 padding |
| md | 16px | depth 1단계당 들여쓰기, "이동" 모달 내부 padding |
| lg | 24px | hover 액션 버튼 크기(24px 정사각형, 재사용 — 신규 값 아님) |
| xl | 32px | 트리 노드 행 높이(32px, 툴바 버튼과 동일 값 재사용) |
| 2xl | 48px | (이 phase 미사용) |
| 3xl | 64px | (이 phase 미사용) |

Exceptions: 사이드바 헤더 행 높이 40px는 "라벨 line-height + 상하 패딩"의 합성 값이나 구성 요소(8/16px 패딩)가 전부 스케일 내부라 예외로 취급하지 않음. 그 외 예외는 위 Layout 섹션의 사이드바 폭(260px) 하나뿐.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|

| Label | 12px | 600 (semibold) | 1.4 |
| Heading | 16px | 600 (semibold) | 1.2 |

폰트 weight는 Phase 1/2와 동일하게 **400·600 2종만** 사용(700 미사용).

## Color

Phase 1이 이미 이식한 `src/app/globals.css` 토큰을 그대로 재사용(재정의 없음):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (`--bg`) | 사이드바 배경, 컨텍스트 메뉴/모달 배경 |
| Secondary (30%) | `#f8fafc`(`--surface`), `#eef2f6`(`--surface-2`), `#e5e7eb`(`--border`) | 노드 hover 배경, 메뉴 항목 hover 배경, 사이드바 구분선 |
| Accent (10%) | `#2563eb`(`--accent`) | 아래 "Accent reserved for" 목록에 한정 |
| Destructive | `#dc2626`(`--destructive`) | 삭제 컨텍스트 메뉴 항목 텍스트, 삭제 확인 다이얼로그(기존 `ConfirmDialog` `destructive` prop 재사용), 사이클 거부 드래그 피드백 |

**Accent 보조 토큰:** `--accent-strong: #1d4ed8`(사용 안 함, 이 phase엔 hover 대상 버튼류 없음), `--accent-weak: #eff6ff`(선택/드롭 대상 배경).

**Accent reserved for (명시 목록 — 포괄 지정 금지):**
- 선택된(활성) 트리 노드 배경 `var(--accent-weak)` + 텍스트 색 `var(--accent)` (`.tabbar-btn.active` 패턴 재사용)
- 드래그 중 **유효한** 드롭 대상 노드의 배경 `var(--accent-weak)` + 1px solid `var(--accent)` 아웃라인
- 인라인 이름변경 입력 필드의 focus 아웃라인
- 사이드바 헤더 "새 폴더" 버튼의 focus 아웃라인

이 외 요소(hover 액션 버튼 기본 상태, 체브론, 폴더 아이콘 기본색)는 accent를 쓰지 않는다 — `var(--muted)`/`var(--text)` 중립색만 사용(anti-ai-slop, 과다 강조 방지).

## Tree Node Contract

> 이 phase의 트리는 워크스페이스 루트 노드 + 폴더 노드만 렌더한다. 문서 리프 노드는 Phase 4가 `document.folder_id`와 함께 추가하며, 이 phase는 문서 행을 만들지 않는다(CONTEXT.md deferred).

| 요소 | 값 |
|------|-----|
| 행 높이 | 32px(xl, 툴바 버튼과 동일 재사용), 아이콘 16px(lucide 기본) |
| 들여쓰기 | depth 0(워크스페이스 루트) 좌측 padding 8px(sm). depth N(N≥1)의 폴더는 `8px + 16px × N`(md 단위 누적). |
| 체브론(펼침 토글) | 자식 폴더가 1개 이상인 노드에만 렌더, lucide `ChevronRight` 16px, 펼침 시 `transform: rotate(90deg)`(별도 아이콘 스왑 없음 — 트랜지션 없이 즉시 전환, anti-ai-slop). 자식 없는 노드는 체브론 자리만 16px 빈 공간으로 정렬 유지. |
| 폴더 아이콘 | lucide `Folder` 16px, `var(--muted)` — 펼침 여부와 무관하게 항상 같은 아이콘(열림 아이콘 별도 상태 미도입, 체브론 회전만으로 충분) |
| 워크스페이스 루트 아이콘 | 없음(아이콘 미사용) — 굵은 라벨 텍스트만으로 트리 최상위임을 표시 |
| 라벨 | Body(13/400), 긴 이름은 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`(카드 타이틀과 동일 관례, `WorkspaceCard.module.css` 재사용) |
| 기본(default) | 배경 투명, 텍스트 `var(--text)` |
| hover | 배경 `var(--surface-2)`, hover 액션 버튼(kebab) 노출 |
| 선택(selected) | 배경 `var(--accent-weak)`, 텍스트 `var(--accent)`, weight 600. 클릭 시 토글되며 "새 폴더" 생성의 기본 부모 컨텍스트로 쓰인다(문서 열기 개념은 Phase 4). |
| 인라인 이름변경 활성 | 라벨이 `<input>`으로 전환, 기존 이름이 prefill+전체 선택, 테두리 없음 + `outline: 1px solid var(--accent)`, 폭은 행 안에서 가능한 만큼 채움. Enter/blur = 제출, Escape = 취소(원래 이름 복구, 낙관적 반영 없음 — 서버 응답 대기). |
| 드래그 중 — 유효한 대상 | 배경 `var(--accent-weak)` + 1px solid `var(--accent)` 아웃라인 |
| 드래그 중 — 거부(사이클) 대상 | 배경 `#fef2f2`(destructive weak, 신규 값이나 `--destructive`의 톤 계열), 커서 `not-allowed`. **판정은 클라이언트가 즉시 계산**(트리 전체가 이미 메모리에 로드돼 있으므로 드래그 중인 폴더의 서브트리를 순회해 대상이 그 서브트리에 포함되는지 확인 — API 왕복 불필요). 서버도 동일 트랜잭션에서 재검증(TRD §4, 클라이언트 판정은 UX 보조일 뿐 신뢰 경계 아님). |
| pending(뮤테이션 진행 중) | 영향받는 노드(생성 중인 신규 행 자리, 이름변경/이동/삭제 대상 행)는 `opacity: 0.5` + `pointer-events: none` + 우측에 12px 스피너(`docs/ui-kit.html` `.loader-spinner` 패턴 축소, `border-top-color: var(--accent)`). 서버 확정 전까지 트리 구조는 변하지 않는다(CONTEXT.md — 낙관적 UI 없음). |
| 삭제 완료 후 | 별도 "삭제됨" 시각 상태 없음 — 서버 확정 응답 수신 즉시 서브트리 재조회로 노드가 목록에서 사라진다(휴지통 뷰는 Phase 4). 사라지는 애니메이션은 넣지 않는다(anti-ai-slop, 불필요한 장식 모션). |

## Interaction Contract

> CONTEXT.md 잠금 사항(트리거=우클릭+hover 버튼, 이동=DnD+메뉴 폴백, 이름변경=인라인, 펼침/접힘=비영속)을 그대로 따른다. 아래는 이 phase가 구체화하는 세부 사양.

| 요소 | 값 |
|------|-----|
| hover 액션 버튼 | 각 폴더 노드 우측 끝(24×24, lg 재사용), lucide `MoreHorizontal`, hover 시에만 노출(`opacity:0` → 행 hover 시 `opacity:1`, 트랜지션 없음). 클릭 시 우클릭과 **동일한 컨텍스트 메뉴**를 그 자리에 연다(두 트리거가 같은 메뉴로 수렴 — 잠금 결정의 자연스러운 해석). |
| 컨텍스트 메뉴 스타일 | `docs/ui-kit.html` dropdown-menu 패턴 이식: `background: var(--bg); border: 1px solid var(--border); border-radius: 6px; box-shadow: 0 8px 24px rgba(15,23,42,.08)`. 항목 `padding: 8px 12px; font-size: 13px`, hover 배경 `var(--surface-2)`. |
| 폴더 노드 메뉴 항목(4개) | ① "새 하위 폴더"(lucide `FolderPlus`) ② "이름 변경"(lucide `Pencil`) ③ "이동..."(lucide `FolderInput`) ④ "삭제"(lucide `Trash2`, 텍스트색 `var(--destructive)` — `kebab-menu .danger` 관례 재사용) |
| 워크스페이스 루트 메뉴 항목(1개) | "새 폴더"만 — 루트는 이름변경/이동/삭제 대상이 아니다 |
| 드래그앤드롭 | 네이티브 HTML5 DnD. 폴더 노드는 `draggable`, 드롭 대상은 다른 폴더 노드 또는 워크스페이스 루트 행. `dragover`에서 위 Tree Node Contract의 유효/거부 스타일을 계산, 거부 대상은 `preventDefault()` 호출하지 않아 브라우저 기본 "금지" 커서가 뜨게 둔다. `drop` 성공 시 서버 이동 API 호출 → 응답 대기 중 pending 스타일 → 성공 시 서브트리 재조회. |
| "이동" 폴백 모달 | 기존 `Modal` 컴포넌트 재사용. 타이틀 "'{폴더명}' 이동". 본문에 워크스페이스 루트부터 시작하는 들여쓰기 리스트(현재 트리와 동일 들여쓰기 규칙, 단 이동 대상 폴더 자신과 그 서브트리는 선택 불가 항목으로 회색 처리 `var(--dim)` + `pointer-events:none` — 사이클 방지를 목록 자체에서 시각적으로 배제). 항목 클릭 = 즉시 선택 표시(위 selected 스타일), 하단 "취소"(`Button secondary`)/"이동"(`Button primary`, 선택 전 disabled) 버튼. |
| 새 폴더 생성 | 헤더 "+"버튼 또는 컨텍스트 메뉴 "새 폴더"/"새 하위 폴더" 클릭 시, 대상 위치(루트 또는 우클릭한 폴더)에 **즉시 빈 이름 입력 행이 pending 스타일로 삽입**되지 않는다 — 서버 확정 전 변화 없음 원칙(낙관적 UI 금지)에 따라, 클릭 시 곧바로 이름 입력을 받는 인라인 텍스트 필드(placeholder "새 폴더")가 그 자리에 뜨고, Enter 시 서버로 생성 요청 → 성공 응답 후에야 트리에 실제 노드로 반영된다. 빈 값/공백만 입력 시 제출 비활성화(클라이언트 최소 가드, 최종 검증은 서버). |
| 키보드 접근성 | 인라인 이름변경 입력은 Enter=제출/Escape=취소(위에 명시). 컨텍스트 메뉴는 Escape로 닫힘, 방향키 이동은 이 phase 범위 밖(마우스 우선, 요구사항에 키보드 메뉴 탐색 명시 없음 — YAGNI). |

| Primary CTA | "새 폴더" (헤더 버튼 aria-label 및 컨텍스트 메뉴 항목 라벨) |

| Empty state body | "새 폴더를 만들어 문서를 정리해 보세요." — 사이드바 헤더의 "새 폴더" 버튼을 가리키는 안내, 별도 CTA 버튼을 트리 본문에 중복 배치하지 않는다 |
| Error state (뮤테이션 실패 공통 톤) | "{동작}하지 못했어요. 다시 시도해 주세요." — `DeleteWorkspaceDialog`가 이미 쓰는 톤 재사용. 동작별: 생성="폴더를 만들지 못했어요...", 이름변경="이름을 변경하지 못했어요...", 이동="폴더를 이동하지 못했어요...", 삭제="폴더를 삭제하지 못했어요..." |
| 사이클 거부(클라이언트 즉시 판정, 서버 에러 아님) | 드롭 실패 시 토스트 없이 커서 자체가 "금지" 모양으로 즉시 피드백(Tree Node Contract 참조) — 별도 텍스트 불필요, 시각 피드백만으로 충분(CONTEXT.md "사이클은 거부·시각 피드백"의 문언 그대로) |
| Destructive confirmation | 삭제: "'{폴더명}' 폴더를 삭제할까요?" / 본문 "하위 폴더와 문서가 함께 휴지통으로 이동합니다. 휴지통에서 복원할 수 있어요." / 확인 버튼 "삭제"(destructive). **재입력 확인 없음** — `DeleteWorkspaceDialog`(워크스페이스 삭제, 목록에서 완전히 사라짐)보다 가벼운 확인으로 충분한 이유: 폴더 소프트삭제는 휴지통에서 복원 가능한 되돌릴 수 있는 액션(PRD §2-3)이라 재입력 마찰을 둘 필요가 없다(Claude's Discretion). |
