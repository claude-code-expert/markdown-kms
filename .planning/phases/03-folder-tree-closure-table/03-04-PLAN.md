## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 브라우저 → /api/folders/[id]* | folder id·newParentId·이름이 신뢰 불가한 입력으로 넘어온다. URL에 wsId가 없다. |
| route → requireRole/closure | 권한 관문과 트랜잭션 연산. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04-IDOR | Elevation of Privilege | PATCH/DELETE/move workspaceId 유도 | high | mitigate | 클라이언트가 보낸 workspaceId를 절대 신뢰하지 않고, SELECT workspace_id FROM folder WHERE id=:id로 서버가 직접 구해 requireRole('EDITOR')에 넘긴다(Pitfall 3). 자신이 멤버가 아닌 워크스페이스의 folder는 403. |
| T-03-04-RBAC | Elevation of Privilege | EDITOR+ 게이트 | high | mitigate | requireRole가 매 요청 DB에서 멤버십 재조회, VIEWER/비멤버/비로그인 403(PRD §3). UI 숨김은 보안 아님. |
| T-03-04-CYCLE | Tampering | move 사이클 | high | mitigate | moveFolder가 트랜잭션 안에서 사이클 거부, route가 409로 매핑 — 서버는 클라이언트 사이클 판정을 신뢰하지 않는다. |
| T-03-04-XWS | Tampering | move 크로스ws | high | mitigate | moveFolder의 워크스페이스 불일치를 route가 400으로 매핑. |
| T-03-04-BADID | Denial of Service | 잘못된 uuid path/body | medium | mitigate | z.uuid로 id·newParentId를 uuid 컬럼 도달 전 검증, 원시 Postgres 500 대신 400(WR-05 패턴). |
| T-03-04-SC | Tampering | 패키지 설치 | low | accept | 신규 패키지 없음. |
</threat_model>
