**Marker conventions pinned by this plan (Claude's Discretion within the D-P2-08 contract):** bold `**`, italic `*` (single asterisk — chosen over `_` because `*` has no intra-word emphasis restriction, so wrapping a mid-word selection still emphasizes), strikethrough `~~`, inline code `` ` ``, blockquote line-prefix `> `, bullet `- `, ordered `1. `, task `- [ ] `, HR thematic break `---`, code fence ```` ``` ````. Heading is a line-prefix REPLACE (not a wrap): level 1-4 → `#`..`####`, level 0 → paragraph.
