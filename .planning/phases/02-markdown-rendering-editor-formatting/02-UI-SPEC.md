## Layout & Composition Contract

> D-P2-01/03의 핵심 요구: "풀스크린 2분할"이 아니라 Phase 4가 트리 사이드바+상태 바로 감쌀 수 있는 **조립형 pane 컴포넌트**여야 한다. 이 계약을 어기면 Phase 4에서 재작업이 발생한다(costly reversibility).

| 규칙 | 내용 |
|------|------|
| 컴포넌트 경계 | 에디터 pane과 미리보기 pane을 감싸는 최상위 레이아웃 컴포넌트(예 `EditorPreviewLayout`)는 **컨테이너 높이를 상속**한다 — `height: 100%`만 사용하고 `height: 100vh`/`100dvh`를 컴포넌트 내부에 절대 하드코딩하지 않는다. `100vh`는 `app/(main)/w/[wsId]/page.tsx`(호스트 라우트) 최상위에서만 선언한다. |
| 그리드 구조 | 컴포넌트 내부는 CSS Grid `grid-template-columns: minmax(0,1fr) minmax(0,1fr)` 두 칸(에디터\|미리보기), named area 사용 시 `"editor preview"` 한 줄. Phase 4는 이 grid를 `"sidebar editor preview" / "sidebar editor preview"` + 하단 `"statusbar statusbar statusbar"` row로 감싸며, 이 phase가 만든 editor/preview 두 칸의 내부 마크업은 건드리지 않는다. |
| 분할 비율 | 고정 50% / 50%, 리사이즈 핸들 없음. **Claude's Discretion(ponytail 근거):** 드래그 리사이즈는 Phase 2 요구사항 어디에도 없다 — 필요해지면 Phase 5(레이아웃 전환) 때 재검토. |
| 분할선 | 1px solid `var(--border)` 세로선. 그림자·그라데이션 없음(anti-ai-slop). |
| 스크롤 | 에디터·미리보기 각각 독립적으로 세로 스크롤(`overflow-y: auto`), 서로의 스크롤에 영향 없음(스크롤 동기화는 요구사항에 없음 — 만들지 않는다). |
| 비영속 표시 | D-P2-02 — 저장 표시기·상태 바 없음. 화면에 "저장" 관련 UI를 일절 넣지 않는다(Phase 4가 담당). 새로고침 시 소실은 버그가 아니라 의도된 동작이므로 경고 문구도 넣지 않는다. |

## Toolbar Contract

> D-P2-04/05: 기능형 lucide 아이콘 + 기본 hover 툴팁까지가 Phase 2. Pressed 애니메이션과 300ms 지연 타이밍은 Phase 5로 이연 — 이 phase는 그 둘을 만들지 않는다.

| 속성 | 값 |
|------|-----|
| 배치 | 에디터 pane 상단에 sticky 가로 바 (미리보기 pane 위에는 없음 — 툴바는 에디터에만 작용) |
| 바 높이 | 44px (버튼 32px + 상하 패딩 6px), 배경 `var(--surface)`, 하단 테두리 1px `var(--border)` |
| 버튼 크기 | 32px × 32px (8-point 스케일의 `xl`(32px)과 일치 — 예외 아님) |
| 아이콘 크기 | 16px (lucide 기본, ui-kit `svg.lucide { width:1em; height:1em }` 관례 유지) |
| 버튼 간 gap | 4px (`xs`) — 같은 그룹 내 |
| 그룹 간 구분 | 1px solid `var(--border)` 세로 구분선 + 좌우 8px(`sm`) 마진 |
| 버튼 상태 | **정확히 2개만**: 기본(default) / hover(배경 `var(--surface-2)`, 툴팁 노출). **pressed·"현재 커서 위치의 서식 활성" 표시는 Phase 2 범위 밖**(D-P2-05) — 만들지 않는다. |
| 툴팁 스타일 | hover 시 버튼 하단에 노출, 배경 `var(--text)`(#0f172a), 글자색 `#fff`, font-size 11px, padding 4px 8px, border-radius 4px, box-shadow `0 8px 24px rgba(15,23,42,.08)`(ui-kit dropdown/popover 관례). **지연 없이 즉시 표시**(300ms 지연은 Phase 5). |
| 그룹 시각 순서 (Claude's Discretion, CONTEXT 위임) | ① 헤딩 드롭다운 → ② 인라인 4(Bold·Italic·Strikethrough·Code) → ③ 목록 3(Bullet·Ordered·Task) → ④ 블록 3(Blockquote·CodeBlock·HR) → ⑤ 삽입 3(Link·Image·Table). 좌→우 순서로 배치, 위 그룹 구분선으로 시각적 경계를 준다. |
| 헤딩 드롭다운 | ui-kit `dropdown-trigger`/`dropdown-menu` 패턴 이식: trigger는 버튼(32px, 텍스트+chevron-down 아이콘), 메뉴는 `border:1px solid var(--border); border-radius:6px; box-shadow:0 8px 24px rgba(15,23,42,.08)`, 항목 5개(제목1~4 + 본문) 세로 리스트, 각 항목 `padding:8px 12px; font-size:13px`. |

## Spacing Scale

Declared values (must be multiples of 4) — Phase 1과 동일 스케일 재사용(`src/app/globals.css`에 이미 전역 변수로 존재):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 툴바 버튼 그룹 내부 gap, 인라인 코드 padding |
| sm | 8px | 툴바 그룹 간 마진, 헤딩 드롭다운 메뉴 항목 padding |
| md | 16px | 에디터/미리보기 pane 내부 padding, 기본 요소 간격 |
| lg | 24px | 미리보기 prose 컨테이너 좌우 padding |
| xl | 32px | 툴바 버튼 크기, 호스트 페이지 레벨 패딩 |
| 2xl | 48px | (이 phase에서 미사용 — 페이지 레벨 여백용, 참고로만 유지) |
| 3xl | 64px | (이 phase에서 미사용) |

Exceptions: 툴바 바 전체 높이 44px는 "버튼 32px + 상하 패딩 6px×2"의 합성 값이라 8-point 스케일 그 자체는 아니지만, 구성 요소(32px 버튼, 4/8px 패딩)가 전부 스케일 내부라 예외로 취급하지 않는다. 그 외 예외 없음.

## Typography

> UI 크롬(버튼·라벨·타이틀) 타입 스케일은 Phase 1과 **동일하게 재사용**한다(일관성 우선, 새로 발명하지 않음).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.4 |
| Heading | 16px | 600 (semibold) | 1.2 |
| Display | 20px | 600 (semibold) | 1.2 |

폰트 weight는 Phase 1과 동일하게 **400·600 2종만** 사용한다(700 미사용).

### Markdown Preview Heading Scale (콘텐츠 타입 스케일 — 위 UI 스케일과 별개)

> 위 4행은 "UI 크롬" 스케일 계약이고, 아래는 **사용자가 작성한 마크다운 문서 자체의 시각 위계**(EDIT-01, H1~H4/P가 서로 구별되어야 함)를 위한 별도 콘텐츠 스케일이다. weight는 600 하나만 써서 2-weight 예산을 넘기지 않는다.

| 마크다운 요소 | Size | Weight | Line Height |
|---------------|------|--------|-------------|
| H1 | 28px | 600 | 1.2 |
| H2 | 22px | 600 | 1.2 |
| H3 | 18px | 600 | 1.2 |
| H4 | 16px | 600 | 1.2 (= UI Heading 롤과 동일 크기, 재사용) |
| Paragraph (본문) | 15px | 400 | 1.65 (`docs/ui-kit.html` `#kit-desc` 패턴 그대로 재사용 — 새 값 발명 아님) |
| Inline code / Code block | 13px | 400 | 1.6 (IBM Plex Mono, 에디터 본문 폰트 크기와 통일) |

**출처:** H1~H3은 Body(13)·Heading(16)·Display(20) 사이·이상 위계를 만들되 서로 최소 4px 이상 간격을 두어 육안 구별이 확실하도록 설계한 신규 값. Paragraph 15px/1.65는 ui-kit `#kit-desc` 원본 그대로 가져왔다(발명 아님). H4는 기존 Heading(16px) 롤을 그대로 재사용해 새 값 최소화.

## Color

Phase 1이 이미 `src/app/globals.css`에 이식한 토큰을 그대로 재사용한다(재이식·재정의 없음):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (`--bg`) | 에디터 pane 배경, 미리보기 pane 배경, 헤딩 드롭다운 메뉴 배경 |
| Secondary (30%) | `#f8fafc` (`--surface`), `#eef2f6` (`--surface-2`), `#e5e7eb` (`--border`) | 툴바 바 배경, 버튼 hover 배경, pane 분할선, 인라인 코드 배경 |
| Accent (10%) | `#2563eb` (`--accent`) | 아래 "Accent reserved for" 목록에 한정 |
| Destructive | `#dc2626` | **이 phase에는 해당 없음** — 서식 삽입/토글은 파괴적 액션이 아니다(삭제·되돌릴 수 없는 액션 없음). 토큰만 전역에 존재, 이 phase UI에서 사용하지 않는다. |

**Accent 보조 토큰:** `--accent-strong: #1d4ed8`(hover), `--accent-weak: #eff6ff`(선택 배경).

**Accent reserved for (명시 목록 — 포괄 지정 금지):**
- 미리보기에서 렌더된 링크(`<a>`) 텍스트 색
- 에디터 텍스트 선택(selection) 배경 — `var(--accent-weak)`
- 에디터 caret(커서) 색 — `var(--accent)`
- GFM 태스크 체크박스 checked 상태 색 — `accent-color: var(--accent)` (네이티브 `<input type="checkbox">` CSS 프로퍼티, 커스텀 마크업 불필요)
- 헤딩 드롭다운 trigger의 focus 테두리

이 외 요소(툴바 버튼 hover, 코드 블록 배경, 인용문 좌측 보더 등)는 accent를 쓰지 않는다 — 코드 블록은 `--code-bg`(#0f172a, ui-kit 원본), 인용문 좌측 보더는 `var(--border-strong)`을 쓴다(중립색, anti-ai-slop 준수).

## Preview Pane Prose Contract

> `docs/ui-kit.html`에는 마크다운 전용 prose 스타일이 없다(가리키는 `preview-host`는 컴포넌트 갤러리의 범용 미리보기 컨테이너일 뿐 — 이 phase가 최초로 prose 표면을 정의한다). 아래는 CommonMark 0.31.2 + GFM(취소선/태스크/표) 렌더 출력에 적용할 CSS 계약이다.

| 요소 | 스타일 |
|------|--------|
| 컨테이너 | padding `24px`(lg), 폰트 IBM Plex Sans, 최대 폭 제한 없음(pane 폭 = 100%) |
| h1~h4 | 위 "Markdown Preview Heading Scale" 값. margin-top `24px`(lg), margin-bottom `8px`(sm) |
| p | 15px/400/1.65, margin-bottom `16px`(md) |
| ul/ol | 기본 브라우저 마커 유지(`disc`/`decimal`), 좌측 padding `24px`(lg), 항목 간 margin-bottom `4px`(xs) |
| task list (`li:has(input[type=checkbox])`) | 마커 없음(`list-style:none`), `input[type=checkbox][disabled]` + `accent-color: var(--accent)`, 체크박스와 텍스트 간 gap `8px`(sm) |
| blockquote | 좌측 보더 3px solid `var(--border-strong)`, padding-left `16px`(md), 색 `var(--muted)` |
| code(inline) | 배경 `var(--surface-2)`, padding `2px 4px`, border-radius `4px`, font IBM Plex Mono 13px |
| pre > code(블록) | 배경 `var(--code-bg)`(#0f172a), 글자색 `#cbd5e1`, padding `16px`(md), border-radius `8px`, `overflow-x:auto`(긴 줄 가로 스크롤 — overflow 계약), font IBM Plex Mono 13px/1.6. **구문 강조 없음**(D-P2-10) — language info string은 `class="language-{lang}"`로만 통과, highlight.js/prism 등 미도입 |
| hr | `border: none; border-top: 1px solid var(--border); margin: 24px 0` |
| table (GFM) | `border-collapse: collapse; width: 100%`, wrapper에 `overflow-x: auto`(긴 표 가로 스크롤), `th/td { border: 1px solid var(--border); padding: 8px 12px; text-align: left }`, `th { background: var(--surface); font-weight: 600 }` |
| a (link) | 색 `var(--accent)`, `text-decoration: underline` (밑줄로 링크임을 이중 표시 — 색만으로 구분하지 않음, 접근성) |
| 긴 텍스트/URL | 컨테이너에 `overflow-wrap: break-word` — 줄바꿈 없는 긴 단어·URL도 pane 폭을 벗어나지 않는다 |
