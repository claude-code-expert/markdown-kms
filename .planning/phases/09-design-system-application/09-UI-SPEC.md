## Typography

전역(라이트/다크 공통) — 기존 IBM Plex Sans/Mono를 전면 대체(D-05). 웨이트는 정확히 2종만 선언한다: **regular 400** / **semibold 600**(DM Sans 500·700 폰트 파일은 이식하되 이번 phase의 UI 크롬에서는 쓰지 않는다 — 향후 필요 시를 위한 자산일 뿐, 웨이트 소프 방지). 사이즈는 정확히 4종만 선언한다(체커 상한).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (본문·인라인 코드·코드 블록·에디터 소스 포함) | 14px | 400 | 1.5 |
| Label (캡션·메타·배지) | 12px | 600 | 1.4 |
| Heading (카드 제목·문서 제목·섹션 제목) | 16px | 600 | 1.3 |
| Display (페이지 타이틀 — 예: "워크스페이스") | 24px | 600 | 1.2 |

**Code/Mono는 별도 사이즈가 아니라 Body 역할에 통합한다(4사이즈 상한 준수).** DM Mono는 `font-family`만 다르고 크기는 Body와 동일한 14px/400/1.5 — 코드 블록·인라인 코드·에디터 소스 표시 전부 이 행을 참조한다(기존 wireframe의 13px 코드 텍스트는 14px로 흡수, 시각 차이 무시 가능한 수준).

와이어프레임 참고 매핑: `.tt`(24px/700)→Display(600으로 다운시프트, 2웨이트 제약), `.tb`(15px/700)→Heading(16px/600), `.t`(13px/400)→Body(14px/400), `.tm`/`.lbl`(12px/10px)→Label(12px/600, 자간은 필요시 `letter-spacing: 0.02em`로 대체).

폰트 로딩: `docs/design_system/fonts/*.woff2`(dm-sans-400/500/600/700, dm-mono-400) → `public/fonts/`로 복사, `@font-face` + `font-display: swap`, `src/app/globals.css`(또는 별도 `fonts.css` import)에서 선언. Next.js `next/font/local`도 대안(둘 중 실행 단계 재량, CLAUDE.md CSS Modules 원칙과 충돌 없음).

## Radius Scale

D-05 전역 교체 대상 — 기존 컴포넌트별 개별 `border-radius`(4~12px 혼재) 값을 아래 3단 스케일로 통일한다. `docs/design_system/DESIGN.md` Layout 원천: 6px/12px/18px, squircle(superellipse) 적용.

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | 6px | 버튼, 인풋, 배지, 태그 |
| `--radius-md` | 12px | 카드, 모달, 드롭다운 |
| `--radius-lg` | 18px | 페이지 레벨 컨테이너(에디터 셸 프레임, 워크스페이스 리스트 컨테이너) |

**Squircle 구현 방식(재량 확정):** `corner-shape: squircle`은 2026년 8월 현재 주요 브라우저(Chrome stable/Safari/Firefox)에서 광범위하게 지원되지 않는 실험적 CSS 프로퍼티다. `@supports (corner-shape: squircle)` 블록으로 점진적 향상(progressive enhancement)만 적용하고, 미지원 브라우저는 동일한 6/12/18px 값의 평범한 `border-radius`로 폴백한다 — 폴백이 곧 표준 라운드 코너이므로 시각 회귀 리스크 없음.

```css
.card {
  border-radius: var(--radius-md); /* 폴백: 항상 적용 */
}
@supports (corner-shape: squircle) {
  .card {
    corner-shape: squircle;
  }
}
```

## Motion Tokens

D-05 전역 교체 대상. `docs/design_system/DESIGN.md` Layout posture 원천.

| Token | Value | Usage |
|-------|-------|-------|
| `--duration-fast` | 180ms | 버튼 hover, 포커스 링, 색상 전환 |
| `--duration-standard` | 240ms | 드롭다운/모달 열림-닫힘, 토글 상태 전환 |
| `--duration-slow` | 300ms | 툴팁 표시(EDIT-10 기존 300ms 규정과 일치 — 값 변경 없이 토큰명만 부여) |
| `--ease-fluid` | `cubic-bezier(.36,.66,.6,1)` | 색상/아웃라인 전환(hover, focus) |
| `--ease-elastic` | `cubic-bezier(.42,0,.58,1.8)` | transform(버튼 hover 시 살짝 overshoot) |

**Press 피드백:** 클릭 시 색상 플래시가 아니라 `transform: scale(0.98) translateY(1px)` (2% 축소 + 1px 하강), `--duration-fast` + `--ease-elastic`.

**스코프 밖(이번 phase에 불필요, 명시적 스킵):** DESIGN.md가 언급하는 스크롤 트리거 카드 fade-up(`animation-timeline: view()`)은 Phase 9의 4개 성공 기준 어디에도 걸리지 않는 순수 장식 모션이며, `animation-timeline: view()`는 브라우저 지원이 Chrome 계열로 제한적이다 — 구현하지 않는다. 필요해지면 별도 phase에서 재검토.
