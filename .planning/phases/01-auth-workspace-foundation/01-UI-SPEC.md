## Design System

| Property | Value |
|----------|-------|
| Tool | none — shadcn 미도입 |
| Preset | not applicable |
| Component library | none — 순수 CSS Modules + `docs/ui-kit.html` 컴포넌트 이식 |

**shadcn 미도입 근거 (이미 결정됨, 재질문 대상 아님):** TRD §1이 "스타일 = CSS Modules + `docs/ui-kit.html` 토큰, Tailwind는 토큰 이중화만 만든다"고 명시. shadcn은 Tailwind 기반이라 이 결정과 정면 충돌한다. 새 UI는 `docs/ui-kit.html`의 CSS 변수·컴포넌트 마크업을 CSS Modules로 그대로 이식한다.

**Phase 1에서 이식할 ui-kit 컴포넌트:** Button(#4) · Card(#5) · Form(#12) · Input Field(#15) · Modal(#19) · Confirm Dialog(#33). 각 컴포넌트의 원본 HTML/CSS는 `docs/ui-kit.html`에서 `id: 'button'` 등으로 검색 가능.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 아이콘 간격, 폼 필드 내부 라벨-인풋 gap |
| sm | 8px | 버튼 그룹 gap, 모달 액션 버튼 gap |
| md | 16px | 기본 요소 간격, 버튼 가로 패딩 |
| lg | 24px | 모달 박스 패딩, 섹션 패딩 |
| xl | 32px | 카드 대시보드 페이지 패딩, 레이아웃 gap |
| 2xl | 48px | 로그인/가입 페이지 상단 여백 |
| 3xl | 64px | 페이지 레벨 여백 (사용 시) |

**Exceptions (ui-kit.html 컴포넌트 내부 값 — 이식 원본 그대로, 재반올림하지 않음):**
- 버튼 세로 패딩 `8px`(btn), 폼 제출 버튼 `9px 14px`(form-submit) — ui-kit 원본 그대로 이식
- 모달 액션 버튼 `7px 14px`(modal-btn), 확인 다이얼로그 버튼 `7px 14px`(cf-btn)
- 카드 브랜드 헤더 `20px 20px 14px`(kit-brand) — Phase 1 대시보드 헤더에 미적용(참고용)
- 입력 필드 패딩 `8px 12px`(form-input, input-field) — 4의 배수 준수, 예외 아님

이 예외들은 `docs/ui-kit.html`의 기존 컴포넌트 CSS를 문자 그대로 이식한 값이다. 새로 만드는 페이지 레벨 레이아웃(카드 그리드, 페이지 패딩)은 위 8-point 스케일을 따른다.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.4 |
| Heading | 16px | 600 (semibold) | 1.2 |
| Display | 20px | 600 (semibold) | 1.2 |

**출처 및 결정:**
- Body/Label 크기는 `docs/ui-kit.html`의 form-input(13px)·form-label(12px)에서 그대로 가져옴.
- Heading은 modal-title 계열(원본 15~16px, weight 600~700 혼재)을 **16px/600으로 통일**했다. ui-kit 원본은 컴포넌트마다 15px/16px, 600/700이 섞여 있으나, 본 스펙은 정확히 2 weight(400/600)만 선언하는 규칙을 지키기 위해 700을 쓰지 않고 16px/600 하나로 단일화했다. 대상: 워크스페이스 생성 모달 제목, 삭제 확인 다이얼로그 제목.
- Display(20px/600)는 ui-kit에 없는 신규 토큰이다 — 로그인/가입 페이지 타이틀, 카드 대시보드 페이지 타이틀("내 워크스페이스")에 사용. 8-point 스케일과 무관한 타이포 스케일이라 4px 단위 제약 없음, 기존 13/16px 사이에 위계를 만들지 않도록 간격을 두어 20px로 결정.
- 폰트 weight는 **400(regular)·600(semibold) 2종만** 사용한다. 700(bold)은 Phase 1 범위(카드 가격 등 커머스 UI 아님)에 불필요해 제외.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (`--bg`) | 페이지 배경, 카드 배경, 모달 배경, 인풋 배경 |
| Secondary (30%) | `#f8fafc` (`--surface`), `#eef2f6` (`--surface-2`), `#e5e7eb` (`--border`) | 카드 대시보드 배경, 폼 섹션 배경, 테두리선 |
| Accent (10%) | `#2563eb` (`--accent`) | 아래 "Accent reserved for" 목록에 한정 |
| Destructive | `#dc2626` | 워크스페이스 삭제 버튼, 삭제 확인 다이얼로그 확인 버튼, 폼 에러 텍스트/테두리 |

**Accent 보조 토큰 (ui-kit `:root` 원본):** `--accent-strong: #1d4ed8`(hover), `--accent-weak: #eff6ff`(선택/포커스 배경 필요 시).

**Accent reserved for (명시 목록 — "모든 인터랙티브 요소"처럼 포괄 지정 금지):**
- 가입/로그인 폼 제출 버튼(primary CTA) 배경
- "워크스페이스 만들기" 버튼 배경
- 인풋 필드 focus 테두리·outline (`:focus { border-color: var(--accent); outline: 2px solid var(--accent) }`)
- 워크스페이스 생성 모달의 확인 버튼 배경

이 외의 요소(카드 테두리, 비활성 텍스트, 보조 버튼)는 accent를 쓰지 않는다. 활성 워크스페이스 카드 강조는 색이 아니라 두께·명도로 표현한다 (ui-kit `.kit-item.active` 패턴 — anti-ai-slop 준수, `docs/ui-kit.html` 주석 "활성 표시는 색·테두리·라디우스 없이 굵기와 명도로만").

## Copywriting Contract

| Element | Copy |
|---------|------|
| 가입 CTA | "가입하기" |
| 로그인 CTA | "로그인" |
| 워크스페이스 생성 CTA | "워크스페이스 만들기" (트리거 버튼) / 모달 내 확인 버튼 "만들기" |
| 가입 처리 중 (로딩) | 버튼 라벨이 "가입하기" → "가입하는 중…"으로 전환, disabled |
| 로그인 처리 중 (로딩) | 버튼 라벨이 "로그인" → "로그인하는 중…"으로 전환, disabled |
| Empty state | 해당 없음 — 가입 즉시 기본 워크스페이스(EDITOR)에 자동 편입되므로(AUTH-03) 카드 대시보드가 0개 상태로 렌더링되는 경로가 없다 |
| 에러 — 이메일 중복 (가입) | "이미 사용 중인 이메일이에요. 다른 이메일로 시도하거나 로그인해 주세요." |
| 에러 — 비밀번호 정책 미달 (가입) | "비밀번호는 8자 이상이어야 합니다." |
| 에러 — 로그인 실패 | "이메일 또는 비밀번호가 올바르지 않습니다." (계정 존재 여부를 노출하지 않는 통합 문구) |
| 에러 — 네트워크/서버 오류 (공통) | "일시적인 오류가 발생했어요. 잠시 후 다시 시도해 주세요." |
| 에러 — 권한 부족 (403, WS-01) | "이 작업을 수행할 권한이 없습니다." |
| 워크스페이스 생성 실패 | "워크스페이스를 만들지 못했어요. 잠시 후 다시 시도해 주세요." |
| 워크스페이스 삭제 확인 (destructive, D-15 GitHub식 이름 재입력) | 제목: "워크스페이스를 삭제할까요?" / 본문: "'{워크스페이스 이름}'과(와) 그 안의 모든 문서·폴더가 영구적으로 사라지며 되돌릴 수 없습니다. 계속하려면 워크스페이스 이름을 정확히 입력하세요." / 입력값이 이름과 일치할 때까지 확인 버튼("삭제") disabled |
| 워크스페이스 삭제 성공 | 목록에서 즉시 제거 (별도 토스트 카피는 이 phase 범위 밖 — 필요 시 planner가 ui-kit Toast(#35) 이식 여부 판단) |

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | 워크스페이스 카드 대시보드 | ✅ covered | AUTH-03에 의해 가입 즉시 기본 워크스페이스(EDITOR)에 자동 편입되므로 대시보드가 0개로 렌더링되는 경로 자체가 없다 — "Empty state" 행 참조 |
| loading | 가입/로그인 제출 버튼 | ✅ covered | 버튼 라벨 전환 + disabled로 표시, 별도 스피너 컴포넌트 없음(Copywriting Contract "처리 중" 행 참조) |
| error | 가입/로그인/워크스페이스 생성/삭제 실패 | ✅ covered | 각 실패 케이스의 정확한 문구가 Copywriting Contract에 명시됨 |
| populated | 워크스페이스 카드 대시보드 (1개 이상) | ✅ covered | 카드 그리드 레이아웃, 최소 1장(기본 워크스페이스)부터 표시 |
| zero-one-many | 사용자 소속 워크스페이스 수 | ✅ covered | 1개(기본만) ~ N개(직접 생성 추가) 모두 동일 카드 그리드 컴포넌트로 처리, 그리드는 auto-wrap |
| overflow | 워크스페이스 이름 텍스트 (카드 타이틀) | ✅ covered | ui-kit `.kit-item-name` 패턴과 동일하게 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis` 한 줄 말줄임 적용 |
| long-text | 사용자 이름 입력 (가입 폼) | 🧪 backstop | 표시부는 카드/멤버 목록에서 말줄임 처리 가정 — 실제 렌더 검증은 executor가 극단값(예: 100자 이름)으로 시각 확인 필요 |
| long-text | 워크스페이스 이름 최대 길이 | ⚠ unresolved | REQUIREMENT/PRD/TRD 어디에도 이름 필드 최대 길이 제약이 없다(DB는 `text`, 무제한). planner는 합리적 상한(예: `maxlength=100`, 서버 zod 동일 상한)을 가정으로 명시하고 plan에 남길 것 |
